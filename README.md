# PPT Online

🚧 **Proyecto en desarrollo**

Versión fullstack y multijugador de Piedra, Papel o Tijera.

El proyecto parte de una versión frontend desarrollada anteriormente y actualmente
lo estoy transformando en una aplicación online en la que dos jugadores puedan
conectarse a una misma sala y jugar en tiempo real.

## Objetivo

Construir una aplicación fullstack que permita:

- Crear y unirse a salas.
- Conectar dos jugadores.
- Sincronizar el estado de la partida en tiempo real.
- Registrar las elecciones de cada jugador.
- Determinar y mostrar el resultado de cada partida.

## Tecnologías

**Frontend**
- TypeScript
- Web Components
- Firebase Realtime Database

**Backend**
- Node.js
- Express
- TypeScript
- Firebase

## Estado actual

Actualmente estoy trabajando en la creación y conexión a salas y en la
sincronización del estado de los jugadores mediante Firebase Realtime Database.
